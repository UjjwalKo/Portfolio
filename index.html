End-to-end data engineering projects, pulled from my GitHub.

Walmart Lakehouse: dbt + Databricks + Airflow

A medallion-style analytics pipeline that ingests CDC data into Databricks, then transforms and tests it with dbt, all orchestrated by Airflow in Docker.

View repository ↗
Bronze→Silver (incremental)→OBT→Gold facts & dims
  • Orchestration: an 11-task Airflow DAG triggers the Databricks CDC job, waits for success, then runs dbt step by step.
  • Data quality: source freshness checks plus dbt tests after every silver layer.
  • Modelling: incremental silver models with processed_at metadata, a consolidated business OBT, and gold fact tables with snapshots.
  • Deployment: Dockerized Airflow with env-based Databricks credentials.

News ETL: Spark + Airflow + MinIO

A modular, containerized ETL that fetches real news articles and refines them through Bronze, Silver and Gold layers into an analytics-ready MySQL table.

View repository ↗
News API→Bronze · MinIO→Silver · MinIO→Gold · MySQL
  • Config as code: the DAG, schedule, retries and Spark resources are all defined in a versioned JSON file.
  • Idempotent loads: URL-hash deduplication means reruns never create duplicates.
  • Auditability: audit columns at every stage, required-field validation, and archived history of old gold records.
  • Modular jobs: separate extract, transform and load Spark scripts, reproducible with Docker Compose.

Spotify Data Pipeline on Azure

Azure Data Factory pipelines that move data from Azure SQL into a Data Lake incrementally, using a CDC watermark instead of full reloads.

View repository ↗
Azure SQL→Copy activity→Data Lake (Parquet)
  • Incremental ingestion: a Lookup reads the last CDC value, the Copy activity pulls only newer rows, and a Script step stores the new maximum.
  • Metadata-driven: a ForEach loop with parameterized SQL, JSON and Parquet datasets handles many tables with one pipeline.
  • Clean output: empty files are deleted automatically when there is no new data.
  • Alerting: a Web activity raises alerts when a run fails.
